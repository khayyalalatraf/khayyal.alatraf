# عُدّة عروض العملاء — خيال الأطراف العقارية

أدوات بناء العروض المخصّصة بصيغة PDF بهوية خيال الأطراف. لا يُنشر على الموقع (مجلد يبدأ بـ `_`). **لا تُرفع العروض نفسها ولا أسماء الجهات إلى هذا المستودع لأنه عام**؛ تُبنى في مجلد مؤقت وتُرسل للمالك فقط.

## التجهيز
```bash
cd /home/claude && GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 --filter=blob:none --sparse https://github.com/google/fonts google/fonts && cd google/fonts && git sparse-checkout set ofl/tajawal ofl/notokufiarabic
```
البناء: `python3 _proposals-kit/build.py body.html out.pdf "عنوان"` — يدمج head.html + body + about.html + contact.html ويُخرج PDF عبر Chromium.

## منهجية العرض (المرجع: example_body.html — عرض تحالف الوسطاء)
1. **ابحث عن الجهة أولاً:** نشاطها، مدينتها وفروعها، مشاريعها المعلنة (أوقاف، مقرات، توسعات، سكن موظفين)، قيادتها. استخرج 2–3 حقائق منشورة موثوقة تُذكر في الخطاب لإظهار الاطلاع. لا تذكر ما لم تتحقق منه، ولا تخترع تعاوناً سابقاً.
2. **اختر 3–6 خدمات** من فروع النشاط ترتبط مباشرة باحتياجها، واكتب لكل منها كيف تخدمها تحديداً.
3. **البنية (مختصرة، 5–9 صفحات):** غلاف (مقدَّم إلى / مقدَّم من) ← خطاب يبدأ «يسرّنا في خيال الأطراف العقارية…» (بلا كلمة مؤسسة في الافتتاحية) ← `{{ABOUT}}` ← لماذا يهمكم/فهم الاحتياج ← أوجه التعاون (جدول: المجال · ما نقدّمه · صيغة المقابل) ← قسم «الحماية القانونية» عند الحاجة ← القيمة للطرفين ← مستويات الشراكة الثلاثة ← الحوكمة والضوابط ← الخطوة التالية + `{{CONTACT}}`.
4. **لغة وسيط عقاري خبير:** مباشرة ومقنعة، وملاحظة «من الميدان» واحدة على الأقل.

## ثوابت
- الطرف: مؤسسة خيال الأطراف للتجارة (الاسم التجاري: خيال الأطراف العقارية)، رخصة فال 1200034111، الرياض حي العليا. التوقيع: عمر سعود عيضه الجعيد — مالك مؤسسة خيال الأطراف للتجارة.
- الوساطة بفروعها كافة؛ «إبرام العقود الإلكترونية» فرع لا المحور. لا تصف المنشأة بـ«موثّق»، وهي «مؤسسة» لا «شركة».
- لدينا **اتفاقية تعاون قائمة مع شريك قانوني متخصص** — يُذكر دون اسم أو تواصل، والخدمات القانونية يقدّمها الشريك ويفوترها مباشرة.
- لا عمولة على أتعاب المحامين؛ لا تقاسم عمولة وساطة إلا مع وسيط مرخّص بعقد فرعي عبر منصة الهيئة؛ للإعلاميين: المقابل رسوم رعاية/إعلان لا عمولة صفقات.
- الجهات الحكومية: قنوات رسمية فقط ولا هدايا. البيانات الشخصية بموافقة.
- أي إعفاء أو سعر تفضيلي يُكتب «مقترحاً» ويُنبَّه المالك ليؤكده قبل الإرسال.

## الفحص قبل التسليم
حوّل الصفحات إلى صور (`pdftoppm -r 40`) وانظر إليها: لا عنوان يتيم أسفل صفحة، ولا صفحة شبه فارغة، ولا نص عربي/لاتيني مختلط مقلوب (ضع الروابط في `<span class="ltr">` منفصلة عن النص العربي). اجعل القسم الأخير صفحة مستقلة إن انقسم.
